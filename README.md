One funny single-line reply from a hopeless tech support agent to a
desperate customer, entered in the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)
"Have You Tried Turning It Off?" ($10 pot, free entry).

## The entry

> Have you tried turning it off and on again? I ask everyone — it's the one fix that's never failed me, except every single time I've tried it.

141 characters — inside the gate's 1–199 character limit. The twist is the
agent's own cheerful uselessness: the one fix he's never seen fail is the
one that fails him every single time. The customer is never the butt of it.

## How it works

`main.py` writes that exact line (no trailing newline) to
`/output/entry.txt` — honouring `ENTRY_OUT` or `ENTRY_OUT_DIR` when the
harness sets them — and prints the same text to stdout.

```sh
python3 main.py
```
